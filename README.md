# 🌍 Travel Journal

A simple React project created to practice **dynamic data rendering** and improve understanding of **props**. The app displays travel destinations in a clean card layout, pulling data dynamically instead of hardcoding.

🔗 **Live Link:** [Travel Journal](https://travel-journal-eight-rho.vercel.app/)

---

## 🚀 Features

✅ Dynamic data rendering with props
✅ Reusable card components
✅ Minimal and responsive design
✅ Beginner-friendly React project

---

## 🛠️ Tech Stack

* **React 18** – component-based UI
* **Vite** – fast development build tool
* **CSS3** – styling and layout
* **JavaScript (ES6+)** – app logic

---

## 📂 Project Structure

```
travel-journal/
├── src/
│   ├── components/
│   │   ├── Navbar.jsx         # Top navigation bar
│   │   ├── Card.jsx           # Reusable travel card component
│   ├── data.js                # Travel data (title, location, image, etc.)
│   ├── App.jsx                # Main app, maps data into Card components
│   ├── index.css              # Global styles
│   └── main.jsx               # React entry point
├── package.json
└── vite.config.js
```

---

## ⚡ Getting Started

Clone and run the project locally:

```bash
# Clone the repository
git clone https://github.com/itslokeshx/travel-journal.git  

# Navigate into the project
cd travel-journal  

# Install dependencies
npm install  

# Start the dev server
npm start  
```
